Sessions send customerReference: "merchant-demo" so you can filter them on the dashboard. The button above omits paymentMethods, so checkout offers wallet, card, and deposit. Pass paymentMethods to limit them — one method skips the picker: 


// 1. Create Checkout Session
const response = await fetch('https://pay.pingpay.io/api/checkout/sessions', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'x-api-key': 'YOUR_API_KEY',
  },
  body: JSON.stringify({
    amount: '1000000',
    asset: { chain: 'NEAR', symbol: 'USDC' },
    successUrl: 'https://yoursite.com/success',
    cancelUrl: 'https://yoursite.com/cancel',
    customerReference: 'merchant-demo',
    displayMode: 'popup',
    merchantOrigin: 'https://yoursite.com',
    paymentMethods: ['wallet'],
  }),
});
